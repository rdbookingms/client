Basics

Ownership

The Financial Report adds up this resort's net income (income minus agent pay and recorded expenses) from the start date until today and compares it with the total rent, so you can see whether the rent has been recovered. Leave the start date empty to count every record in the system. Do not record the rent payments themselves as expenses, or they would be counted twice.

Receipt look

Invoice numbering

Continuous numbers are allocated when you save. A distinct prefix for each resort keeps its sequence independent. Existing bookings keep their invoice number.

Fields on booking confirmations

Choose fields to show on this resort's preview and downloaded confirmation. Records keep all fields.

Required booking fields

Ticked fields must be filled in before a booking can be saved. Untick a field to make it optional for this resort. Invoice No. is only typed (and only required) when this resort's numbering is Manual.

Custom booking fields

Enable each field for this resort's booking form and confirmation, then customize its label. Set its place in the booking details table order below. Values are optional and saved with the booking.

Booking details table layout

Set the order of the fields in the booking details table with the arrows. Visible fields fill the table two per row in this order; hidden or empty fields are skipped and the next ones move up. If one field is left over, it spans the full row.
